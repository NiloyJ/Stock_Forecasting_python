This streamlit-based forecasting app lets you forecast any stock you want with analysis and multi-dashboard prediction. It combines real-time market data, technical indicators, and basic time series to explore stocks before putting their money on the line. 

This project is purely educational to revive my python skill. It is advised to see this project as an attempt only, not a mini financial advising machine.

🚀 <h2> Dashboard </h2>

Fetch real-time equity data using Yahoo API 

It shows: 

Overview of companies (Market cap, Industry, etc)

Crucial financial ratios such as PE, EPS, Beta, ROE, Debt-to-Equity, etc

Candlestick & Line charts

Relatie strength index

MACD and moving averages of 20 & 50 days 

Time filters include different time ranges

<h2>🔮 Stock Price Prediction using ARIMA</h2>

ARIMA time-series modeling to forecast future prices

Statinarity check using the ADF test 

Auto differencing order (d) calculation

30-day closing price forecasting


It displays:

RMSE score (model error)

Forecast table

Candlestick chart with:

MA12 & MA26

Forecast overlay
